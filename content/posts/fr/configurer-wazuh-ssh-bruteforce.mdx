Wazuh est un SIEM open source puissant pour la détection d'intrusions. Dans ce tutoriel, on configure la détection des attaques brute force SSH.

## Prérequis

- Wazuh Manager installé (v4.x)
- Agent Wazuh déployé sur le serveur cible
- Accès SSH au serveur surveillé

## Architecture

```
[Serveur SSH] --> [Wazuh Agent] --> [Wazuh Manager] --> [Alertes]
```

## Configuration de l'agent

L'agent Wazuh doit monitorer les logs d'authentification.

<Terminal>
sudo nano /var/ossec/etc/ossec.conf
</Terminal>

Vérifier que la section localfile inclut les logs auth :

```xml
<localfile>
  <log_format>syslog</log_format>
  <location>/var/log/auth.log</location>
</localfile>
```

Redémarrer l'agent après modification.

<Terminal>
sudo systemctl restart wazuh-agent
</Terminal>

## Règles de détection

Wazuh inclut des règles par défaut pour détecter les échecs d'authentification SSH (règle 5710).

<Callout type="info">
La règle 5712 se déclenche après 8 tentatives échouées en 2 minutes, indiquant une probable attaque brute force.
</Callout>

### Créer une règle personnalisée

Pour ajuster le seuil de détection, on crée une règle custom.

<Terminal>
sudo nano /var/ossec/etc/rules/local_rules.xml
</Terminal>

```xml
<group name="local,sshd,">
  <rule id="100001" level="10" frequency="5" timeframe="60">
    <if_matched_sid>5710</if_matched_sid>
    <description>SSH brute force détecté (5 échecs en 60s)</description>
    <mitre>
      <id>T1110</id>
    </mitre>
  </rule>
</group>
```

## Active Response

On peut configurer Wazuh pour bloquer automatiquement les IP attaquantes.

<Terminal>
sudo nano /var/ossec/etc/ossec.conf
</Terminal>

```xml
<active-response>
  <command>firewall-drop</command>
  <location>local</location>
  <rules_id>100001</rules_id>
  <timeout>3600</timeout>
</active-response>
```

<Callout type="warning">
Testez l'active response en environnement de test avant production pour éviter de vous bloquer vous-même.
</Callout>

## Validation

Simuler une attaque pour valider la configuration.

<Terminal>
hydra -l admin -P /usr/share/wordlists/rockyou.txt ssh://target-ip
</Terminal>

Vérifier les alertes dans le dashboard Wazuh ou via CLI.

<Terminal>
sudo cat /var/ossec/logs/alerts/alerts.json | jq 'select(.rule.id == "100001")'
</Terminal>

## Conclusion

Cette configuration permet de :
- Détecter les attaques brute force SSH en temps réel
- Alerter via le dashboard Wazuh
- Bloquer automatiquement les attaquants

Prochaine étape : intégrer les alertes avec un système de notification (Slack, email).
