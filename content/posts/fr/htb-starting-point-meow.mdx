## Reconnaissance

On commence par un scan nmap pour identifier les services actifs sur la cible.

```bash title="nmap scan"
nmap -sV -sC 10.129.1.17
```

```text
PORT   STATE SERVICE VERSION
23/tcp open  telnet  Linux telnetd
```

Le port 23 est ouvert avec un service Telnet.

## Exploitation

Telnet est un protocole non chiffré. On tente une connexion avec le compte `root` sans mot de passe.

```bash
telnet 10.129.1.17
```

Connexion réussie sans authentification. On récupère le flag directement.

```bash
cat flag.txt
```

## Conclusion

Cette box introduit les bases : scan de ports avec nmap et connexion Telnet. Elle montre pourquoi Telnet ne devrait jamais être exposé en production.
